# Glossary

The words that code, docs and screens use for the concepts of the notes app. One term per concept.

## Notes

**Text note**:
A note whose content is a body.
_Avoid_: plain note

**Checklist**:
A note whose content is a list of items.
_Avoid_: list (the notes list is a different thing), todo list

**Body**:
The formatted text of a text note, below its title.
_Avoid_: text, content

**Item**:
One line of a checklist, with its own text and checked state.
_Avoid_: entry, row, task

**Checked item**:
An item that the user ticked.
_Avoid_: done, completed

**Checked items hidden**:
A setting of a checklist: its checked items are not shown.
_Avoid_: folded, done folded, collapsed

**Default colour**:
The colour that a new note gets: Oat. It is one of the note colours, not the absence of one.
_Avoid_: no colour, white

**Position**:
Where a note sits among the notes of its vault, or an item in its checklist.
_Avoid_: order, index

## Where a note is

**Archive**:
The list of notes that the user put away; they stay out of the notes list.

**Trash**:
The list of notes that the user removed. A note in the Trash can be restored until it is purged.
_Avoid_: deleted, bin

**Restore**:
Take a note out of the Trash, back to the list it came from.
_Avoid_: undelete

**Purge**:
Delete a note for good, on every device.
_Avoid_: delete, permanently delete

**Delete**:
Remove an item or a label for good. A note is never deleted: it goes to the Trash, then is purged.

## Vaults

**Vault**:
A closed set of notes with its own labels. Devices that sync share a vault.
_Avoid_: notebook, folder, space

**Label**:
A name that groups notes inside one vault.
_Avoid_: tag, category
